# Portfólio

Site de portfólio pessoal, estático (HTML/CSS/JS), publicado via Cloudflare Pages.

## Desenvolvimento local

Basta abrir `index.html` no navegador, ou servir a pasta com qualquer servidor estático:

```
npx serve .
```

## Deploy

Este repositório está conectado ao Cloudflare Pages: todo push na branch `main` gera um novo deploy automaticamente.
